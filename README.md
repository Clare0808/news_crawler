# 新聞爬蟲

爬取四家大型新聞公司所發布之新聞內容。


## 新聞公司代號對照
| 新聞公司 | 代號 |
| -------- | -------- |
| CNA | 中央社 |
| CTEE | 工商時報 |
| EDN | 經濟日報 |
| Wealth | 財訊 |


## 新聞資料欄位

| 欄位 | 說明 | 
| -------- | -------- |
| Source | 新聞公司 |
| Category | 新聞類別 |
| SubCategory | 新聞子類別 |
| Url | 新聞連結 |
| Header | 新聞標題 |
| CreateTime | 新聞發布時間 |
| Content | 新聞內文 |


## 爬取策略與限制

不同新聞網站之新聞公告數量、追溯日期亦不同。

### 中央社 (CNA)
* 目前只爬取前 10 頁
* CNA 最舊只能抓到 3 天前的新聞

### 工商時報 (CTEE)
* 目前只爬取前 10 頁
* 最舊可能到一年前 (仍須確認)

### 經濟日報 (EDN)
* 目前只爬取前 10 頁
* 同一天的文章數量眾多，後續可依據時間來停止爬蟲

### 財訊 (Wealth)
* 目前只爬取前 100 條
* 新聞可一直往舊的挖


## 資料清洗

```powershell
pip install -r requirements.txt
python clean.py        # 讀 result/*.csv，輸出到 cleaned/
python -m pytest tests # 清洗規則的測試
```

原始 `result/*.csv` 不會被修改。輸出：

| 檔案 | 內容 |
| -------- | -------- |
| `cleaned/news_clean.csv` | 四家合併、清洗後的新聞（UTF-8 BOM，Excel 可直接開） |
| `cleaned/rejected.csv` | 被剔除的新聞與原因 |
| `cleaned/clean_report.md` | 每家來源的處理統計與各規則命中篇數 |

### 做了什麼
* **時間統一**：全部轉成台北時間 ISO 8601，例如 `2026-11-21T16:50:00+08:00`。財訊原本是 UTC，已加 8 小時。
* **重複新聞**
  * 工商時報同一篇掛在多個分類（網址只差最後的分類碼），合併成一筆，`Category` 以「、」列出所有分類。
  * 同來源標題與內文都相同的，只留一筆。
  * 不同來源刊出同一篇稿（多半是中央社供稿）不刪，標上相同的 `DupGroup`。
* **雜訊清除**：統一換行、去全形空白；每家來源的規則寫在 `clean.py` 的 `RULES`，命中的規則記在 `Flags` 欄位。
  * 中央社：開頭圖說、電頭「（中央社記者X台北21日電）」、結尾「（編輯：X）1151121」
  * 工商時報：電頭「【時報記者X台北報導】」、MoneyDJ 轉載的開頭與「...詳全文」
  * 經濟日報：開頭「本文共N字」、獨立成行的「圖／X提供」、MIC 版權聲明
  * 財訊：「延伸閱讀：」、免責聲明、授權轉載說明、雜誌原始標題、嚴正聲明
* **無效內容**：清洗後少於 20 字的剔除（例如只剩「延伸閱讀：」）。
* **來源名稱**：財訊爬蟲把來源寫成「財經」，已更正。

### 新增欄位
| 欄位 | 說明 |
| -------- | -------- |
| Id | `來源代號-網址末段`，可當唯一鍵 |
| SourceCode | CNA / CTEE / EDN / Wealth |
| PublishedAt | 統一後的發布時間 |
| TimeIsPlaceholder | 工商時報紙本文章的時間固定是 03:00，不是實際發布時間 |
| ContentLen | 清洗後內文字數 |
| IsTruncated | 內文不完整（見下方已知問題） |
| DupGroup | 跨來源重複稿的群組編號，空白表示沒有重複 |
| Flags | 這篇命中了哪些清洗規則 |

### 已知問題（清洗無法解決）
* **工商時報 1,831 篇內文不完整**：爬蟲用的列表 API 只給前 200 字摘要，要拿全文必須改爬蟲去抓文章頁。做 NLP 時可用 `IsTruncated` 篩掉，或只用標題。
* 中央社約 7 篇的開頭格式特殊（例如標題直接接在電頭前），圖說沒清乾淨。
