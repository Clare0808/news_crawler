# 新聞爬蟲

爬取四家大型新聞公司所發布之新聞內容。


## 新聞公司代號對照
| 新聞公司 | 代號 |
| -------- | -------- |
| CNA | 中央社 |
| CTEE | 工商時報 |
| EDN | 經濟日報 |
| Wealth | 財訊 |


## 新聞資料欄位

| 欄位 | 說明 | 
| -------- | -------- |
| Source | 新聞公司 |
| Category | 新聞類別 |
| SubCategory | 新聞子類別 |
| Url | 新聞連結 |
| Header | 新聞標題 |
| CreateTime | 新聞發布時間 |
| Content | 新聞內文 |


## 爬取策略與限制

不同新聞網站之新聞公告數量、追溯日期亦不同。

### 中央社 (CNA)
* 目前只爬取前 10 頁
* CNA 最舊只能抓到 3 天前的新聞

### 工商時報 (CTEE)
* 目前只爬取前 10 頁
* 最舊可能到一年前 (仍須確認)

### 經濟日報 (EDN)
* 目前只爬取前 10 頁
* 同一天的文章數量眾多，後續可依據時間來停止爬蟲

### 財訊 (Wealth)
* 目前只爬取前 100 條
* 新聞可一直往舊的挖


## 資料清洗 (後續須進行)
* 處理重複新聞
* 消除無效內容 (如廣告) 或排版 (如換行)
* 刪除無效內容
* 統一時間格式
